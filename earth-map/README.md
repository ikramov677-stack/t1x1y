# Земля

`index.html` — настоящая Земля в браузере: 3D-глобус и плоская карта на спутниковых снимках NASA Blue Marble,
с границами стран Natural Earth и реальной линией дня и ночи. Снимки и границы встроены в файл; из интернета
загружаются только три библиотеки (three.js, d3, topojson) и шрифты.

- Тянуть — вращать или двигать, колесо или два пальца — приближение.
- Поиск страны по-русски → перелёт к ней с подсветкой границы.
- Клик по любой точке: страна, координаты, высота Солнца, местное солнечное время.
- Кнопки: Глобус / Карта, Города, Границы, День и ночь (ночная сторона с огнями городов), Вращение.
- **Города:** 7295 городов с русскими названиями; чем ближе, тем больше подписей. Клик по городу — население, местное время.
- **Маршрут:** между двумя городами или точками — линия кратчайшего пути с самолётом, расстояние, курс, время полёта, разница часовых поясов.
- **Навигация:** кнопки + / − / вся Земля, клавиши ← ↑ → ↓, + / −, 0, «/» — поиск.

`online.html` — онлайн-карта (OpenStreetMap, спутник Esri, рельеф) с поиском адресов и **навигацией по дорогам**
(кнопка 🚗): маршрут на машине, пешком или на велосипеде, расстояние, время и пошаговые подсказки (сервис OSRM на данных OpenStreetMap).

Пересборка `index.html`: `npm install && npm run build` (шаблон — `src/template.html`).

Города: Natural Earth populated places, подготовка — `tools/cities.py` → `data/cities.json`.

Данные: снимки NASA Visible Earth (общественное достояние), границы Natural Earth через world-atlas (общественное достояние).
