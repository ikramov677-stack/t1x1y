# Земля

`index.html` — всё в одном файле: 3D-глобус и карта улиц. Глобус — 3D-глобус и плоская карта на спутниковых снимках NASA Blue Marble,
с границами стран Natural Earth и реальной линией дня и ночи. Снимки и границы встроены в файл; из интернета
загружаются только три библиотеки (three.js, d3, topojson) и шрифты.

- Тянуть — вращать или двигать, колесо или два пальца — приближение.
- Поиск страны по-русски → перелёт к ней с подсветкой границы.
- Клик по любой точке: страна, координаты, высота Солнца, местное солнечное время.
- Кнопки: Глобус / Карта, Города, Границы, День и ночь (ночная сторона с огнями городов), Вращение.
- **Города:** 7295 городов с русскими названиями; чем ближе, тем больше подписей. Клик по городу — население, местное время.
- **Маршрут:** между двумя городами или точками — линия кратчайшего пути с самолётом, расстояние, курс, время полёта, разница часовых поясов.
- **Навигация:** кнопки + / − / вся Земля, клавиши ← ↑ → ↓, + / −, 0, «/» — поиск.

**Карта улиц** открывается из глобуса кнопкой с картой справа, кнопкой «Карта улиц» в карточке города или
подсказкой «Улицы и места здесь →» при сильном приближении; кнопка 🌍 возвращает на глобус в то же место.
Метки «Мои места» видны и на глобусе. Карте улиц нужен интернет (тайлы, поиск, места и маршруты онлайн).
Её исходник — `online.html`, его можно открыть и отдельно:
- **Обзор:** быстрый переход по городам, «Что рядом» — кафе, рестораны, гостиницы, достопримечательности, магазины, аптеки,
  больницы, банкоматы, заправки, парки, остановки (данные OpenStreetMap через Overpass) с часами работы, телефоном и сайтом;
  клик по карте показывает адрес точки.
- **Маршрут:** авто, такси, пешком, велосипед, самокат — время показывается сразу для всех, пошаговые подсказки, время прибытия
  (маршруты OSRM на данных OpenStreetMap).
- **Мои места:** свои метки с названием, значком и заметкой; их можно перетаскивать, строить к ним маршрут,
  скачивать и загружать файлом. Хранятся в браузере.
- Слои: схема, спутник, гуманитарная, рельеф, ночная.

Пересборка `index.html`: `npm install && npm run build` (шаблон — `src/template.html`).

Города: Natural Earth populated places, подготовка — `tools/cities.py` → `data/cities.json`.

Данные: снимки NASA Visible Earth (общественное достояние), границы Natural Earth через world-atlas (общественное достояние).
