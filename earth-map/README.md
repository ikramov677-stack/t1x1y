# Карта Земли

Интерактивная карта реального мира: откройте `index.html` в браузере (нужен интернет).

- **Слои:** спутниковые снимки Esri (с подписями и без), улицы OpenStreetMap, рельеф OpenTopoMap, тёмная карта CARTO.
- **Поиск** любого места (Nominatim / OpenStreetMap).
- **📍** — показать ваше местоположение, **🌗** — текущая граница дня и ночи, **🌍** — вся планета.
- Координаты под курсором; клик по карте — точные координаты точки.

Данные: © участники OpenStreetMap, © Esri и поставщики снимков, © OpenTopoMap, © CARTO.
