# «Дискотека 1986» — тексты для Suno

Suno → **Create → Custom**. В поле **Style of Music** вставить строку «Стиль», в поле **Lyrics** — текст целиком вместе с тегами в квадратных скобках.
Тексты оригинальные, написаны для этой кассеты.

**Советы по генерации**
- К стилям без слова *russian* стоит дописать `russian vocals`: так ударения и произношение будут чище. Для всех треков полезна приписка `1986, analog tape warmth`.
- Нужна длина ≈ 4 минуты. Если вышло короче, используйте **Extend** от последнего припева с тегами `[Chorus] … [Outro] [End]`.
- Генерируйте 2–4 варианта и берите тот, где вокал не «плывёт» в припеве. Позже из припева режется Shorts.
- Готовый файл сохраните в `disco-1986/tracks/` под номером: `01.mp3`, `02.mp3` … `10.mp3`.
